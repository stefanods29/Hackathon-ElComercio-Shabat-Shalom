# Evidencias de la Fase 1

Aquí va el resultado de cada criterio de [`../criterios-de-salida.md`](../criterios-de-salida.md),
un archivo por criterio (por ejemplo `piloto.md` o `moderacion.md`).

Cada archivo dice qué se probó, con qué versión de la app y del backend (commit), en qué
dispositivos, cuándo y con qué resultado. Si algo falló, también lo que se corrigió.

Sin datos personales: ni nombres, ni teléfonos, ni ubicaciones, ni capturas con contenido de
vecinos. Las cifras del piloto van agregadas.
