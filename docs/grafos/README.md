# Grafos

- `dependencias-backend.md`: grafo de dependencias entre módulos del backend, generado con
  `cd backend && npm run graph` (dependency-cruiser). Se actualiza en el mismo PR que cambia
  dependencias y se revisa junto con `npm run boundaries`.
- Los diagramas de flujo, estados y secuencia viven en Mermaid dentro de cada documento
  (`docs/fase-0/plan-de-lotes.md` y los `design.md` de OpenSpec).
